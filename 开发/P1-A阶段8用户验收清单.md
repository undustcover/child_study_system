## 二、启动方式

启动后端：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload --host 0.0.0.0 --port 8000
```

打开家长Web端：

```text
http://localhost:8000
```

启动虚拟设备：

```powershell
.\.venv\Scripts\python.exe scripts\virtual_device.py
```

可选电脑TTS：

```powershell
.\.venv\Scripts\python.exe scripts\virtual_device.py --tts
```

## 三、用户手动验收步骤

### 1. 创建计划

打开：

```text
http://localhost:8000/plans
```

操作：

- 新建一个日历计划。
- 设置开始日期和结束日期包含今天。
- 勾选今天所在星期。
- 添加一个学习任务。
- 添加一个休息任务。

用户判断：

- 创建计划是否顺手。
- 任务项字段是否够用。
- 页面中文表达是否清楚。

### 2. 生成今日任务

当前阶段如果页面没有生成按钮，可用接口生成：

```text
POST http://localhost:8000/api/daily-tasks/generate?date=YYYY-MM-DD
```

其中`YYYY-MM-DD`替换为今天日期。

用户判断：

- 今日看板是否出现任务。
- 任务顺序和时间是否符合预期。
- 没有计划的日期是否不会生成任务。
- 修改计划或任务项后，今日看板和纠错页是否同步显示最新的未开始任务。

### 3. 验证虚拟设备

启动虚拟设备后，确认终端能看到：

- 已连接后端。
- 已收到`device_config`配置同步。
- 已同步今日计划。
- 能看到后端播报。

输入建议：

```text
今天计划
开始学习
暂停
继续
完成了
```

用户判断：

- 这些中文说法是否像孩子会说的话。
- 虚拟设备回复是否自然。
- 多意图、否定句、未听清提示是否可接受。
- 输入“今天计划”或“播报本日计划”时，是否能明确听到/看到当天剩余计划。

### 4. 验证Web页面变化

依次打开：

```text
http://localhost:8000
http://localhost:8000/devices
http://localhost:8000/stats
http://localhost:8000/corrections
http://localhost:8000/language
```

用户判断：

- 首页是否能看懂当前状态。
- 设备页是否能看懂在线状态、设备设置和同步状态。
- 统计页是否足够支持当天复盘。
- 纠错页是否能完成家长修正。
- 语言页是否能看懂播报模板、提醒模板、本地回复和命令短语。

### 5. 验证设备设置

打开：

```text
http://localhost:8000/devices
```

操作：

- 查看当前设备状态。
- 修改“自动同步今日计划”。
- 修改“连接后自动播报今日计划”。
- 修改“断线重连后是否重播”。
- 保存设置。

用户判断：

- 设置项是否容易理解。
- 页面是否能同时看清设备在线状态和当前配置。
- 设置保存后，再启动虚拟设备时，行为是否符合设置预期。

### 6. 验证语言自定义

打开：

```text
http://localhost:8000/language
```

操作：

- 修改“今日计划播报”的一条模板。
- 修改“未识别回复语”。
- 修改“查询今天计划”的命令短语。
- 保存语言设置。
- 重新启动虚拟设备，或使用设备配置同步功能后，再输入新的短语。

用户判断：

- 页面字段是否看得懂。
- 修改文案后，播报语气是否更符合家庭使用。
- 修改命令短语后，虚拟设备是否能按新短语识别。
- “恢复默认文案”是否符合预期。

### 7. 验证纠错

打开：

```text
http://localhost:8000/corrections
```

操作：

- 选择一个今日任务。
- 修改任务状态。
- 修改实际开始时间或结束时间。
- 保存纠错。

用户判断：

- 不写原因是否符合预期。
- 状态选项是否够用。
- 时间修正是否容易理解。

## 四、通过标准

用户验收通过需要满足：

- 家长能独立创建计划。
- 家长能看到今日任务。
- 学生主流程不依赖Web点击。
- 虚拟设备能模拟学生语音执行。
- 开始、暂停、继续、完成的结果符合预期。
- 到结束时间不会自动完成，仍需确认。
- Web端能看到设备状态、统计和纠错入口。
- 设备设置和语言自定义入口可用。
- 设备连接、手动刷新、配置变更后，配置同步链路可用。
- 页面风格、信息密度和中文表达用户可以接受。
