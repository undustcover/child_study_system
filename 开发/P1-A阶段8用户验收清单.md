# P1-A阶段8用户验收清单

## 一、验收定位

阶段8分两层：

- 系统自测：由开发者先跑自动化测试和烟测，确认程序链路没有明显技术错误。
- 用户验收：由用户亲自按真实使用方式操作，判断业务流程、页面体验、语音交互和统计结果是否符合家庭学习场景。

当前系统自测已覆盖：

- 创建日历计划。
- 生成今日任务。
- 生成到点提醒。
- 虚拟设备通过正式WebSocket协议连接。
- 设备收到后端播报并回执播放完成。
- 设备语音命令驱动开始、暂停、继续、完成。
- 学习任务完成后自动开始休息任务。
- 任务、会话、计时段分开记录。
- 暂停时间不计入有效学习时间。
- Web首页可读取当前任务、设备、提醒和统计数据。

## 二、启动方式

启动后端：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload --host 0.0.0.0 --port 8000
```

打开家长Web端：

```text
http://localhost:8000
```

启动虚拟设备：

```powershell
.\.venv\Scripts\python.exe scripts\virtual_device.py
```

可选电脑TTS：

```powershell
.\.venv\Scripts\python.exe scripts\virtual_device.py --tts
```

## 三、用户手动验收步骤

### 1. 创建计划

打开：

```text
http://localhost:8000/plans
```

操作：

- 新建一个日历计划。
- 设置开始日期和结束日期包含今天。
- 勾选今天所在星期。
- 添加一个学习任务。
- 添加一个休息任务。

用户判断：

- 创建计划是否顺手。
- 任务项字段是否够用。
- 页面中文表达是否清楚。

### 2. 生成今日任务

当前阶段如果页面没有生成按钮，可用接口生成：

```text
POST http://localhost:8000/api/daily-tasks/generate?date=YYYY-MM-DD
```

其中`YYYY-MM-DD`替换为今天日期。

用户判断：

- 今日看板是否出现任务。
- 任务顺序和时间是否符合预期。
- 没有计划的日期是否不会生成任务。

### 3. 验证虚拟设备

启动虚拟设备后，确认终端能看到：

- 已连接后端。
- 已同步今日计划。
- 能看到后端播报。

输入建议：

```text
今天计划
开始学习
暂停
继续
完成了
```

用户判断：

- 这些中文说法是否像孩子会说的话。
- 虚拟设备回复是否自然。
- 多意图、否定句、未听清提示是否可接受。

### 4. 验证Web页面变化

依次打开：

```text
http://localhost:8000
http://localhost:8000/devices
http://localhost:8000/stats
http://localhost:8000/corrections
```

用户判断：

- 首页是否能看懂当前状态。
- 设备页是否能看懂在线和同步状态。
- 统计页是否足够支持当天复盘。
- 纠错页是否能完成家长修正。

### 5. 验证纠错

打开：

```text
http://localhost:8000/corrections
```

操作：

- 选择一个今日任务。
- 修改任务状态。
- 修改实际开始时间或结束时间。
- 保存纠错。

用户判断：

- 不写原因是否符合预期。
- 状态选项是否够用。
- 时间修正是否容易理解。

## 四、通过标准

用户验收通过需要满足：

- 家长能独立创建计划。
- 家长能看到今日任务。
- 学生主流程不依赖Web点击。
- 虚拟设备能模拟学生语音执行。
- 开始、暂停、继续、完成的结果符合预期。
- 到结束时间不会自动完成，仍需确认。
- Web端能看到设备状态、统计和纠错入口。
- 页面风格、信息密度和中文表达用户可以接受。
